# desde cero

Link-in-bio de **desde cero**, agencia de diseño, desarrollo web y marketing de Tadeo Betancor.

- Intro con el logo pintado a pincel y transición de papel rasgado.
- Botones desplegables: trabajos, sobre mí y "Quiero mi página" (cuestionario que arma un mensaje de WhatsApp).

Es un solo `index.html` con CSS y JS sin dependencias. Para editar contenido, mirá la sección `CONFIG` al principio del script:
`PROJECTS` (trabajos), `SERVICIOS`, `PREGUNTAS` y `FRANJA`.
